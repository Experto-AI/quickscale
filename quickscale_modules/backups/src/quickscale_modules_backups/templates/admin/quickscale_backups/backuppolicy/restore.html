Admin restore supports either a recorded local PostgreSQL custom dump artifact already present on disk or an uploaded dump file that resolves to exactly one trusted authoritative artifact by recorded checksum and size. This page never materializes remote-only artifacts.

Uploaded files are quarantined temporarily for trusted-match resolution and cleanup. Dry-run validation and restore both require the exact authoritative artifact filename. The existing environment gate still applies to executable restore.
