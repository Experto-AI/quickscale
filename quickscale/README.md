# quickscale

Installation meta-package for the QuickScale Django project generator.

This package bundles [quickscale-core][] and [quickscale-cli][] into a
single installable distribution so end users can run
`pip install quickscale` (or `pipx install quickscale`) and get the full
toolchain in one step.

It contains no application logic of its own.

[quickscale-core]: https://pypi.org/project/quickscale-core/
[quickscale-cli]: https://pypi.org/project/quickscale-cli/
