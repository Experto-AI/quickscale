# Changelog

`CHANGELOG.md` is the canonical QuickScale release history index. Published releases pair each version entry with a single official release note in `docs/releases/` linked from the GitHub tag and release PR. When a release note is prepared before the maintainer completes the manual tag/publish step, the changelog entry and note must say so explicitly and must not imply publication. Use `docs/technical/roadmap.md` for active or unpublished release status. Entries are version-ordered.

- v0.87.0 — unreleased / not yet tagged — Hardening release (in progress). Consolidates a large hardening pass across tenant isolation, module configuration, the generator, and disaster recovery.
  - **SA7.1 — `organization_created` signal replaces CRM bootstrap reverse-import.** Defined and dispatched an `organization_created` Django signal from `OrgCreateForm.save()` in the orgs module.   - **SA7.2 — Fail-hard the auth-adapter import fallback.** Replaced the silent `try/except ImportError` fallback in `orgs/adapters.py` with an unconditional import from `quickscale_modules_auth.adapters.QuickscaleAccountAdapter`. If the auth module is not on the Python path, the `ImportError` now propagates as a hard failure at module load time instead of silently degrading to `DefaultAccountAdapter`. The auth module is always importable via PYTHONPATH without Django app registration, so no `INSTALLED_APPS` change was needed.
