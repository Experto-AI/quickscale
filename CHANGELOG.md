# Changelog

`CHANGELOG.md` is the canonical QuickScale release history index. Published releases pair each version entry with a single official release note in `docs/releases/` linked from the GitHub tag and release PR. When a release note is prepared before the maintainer completes the manual tag/publish step, the changelog entry and note must say so explicitly and must not imply publication. Use `docs/technical/roadmap.md` for active or unpublished release status. Entries are version-ordered.

- v0.87.0 — unreleased / not yet tagged — Hardening release (in progress). Consolidates a large hardening pass across tenant isolation, module configuration, the generator, and disaster recovery.
  - **SA48 — Fail hard the shared orgs `get_client_ip()` trusted-proxy settings reads.** `USE_X_FORWARDED_FOR`/`TRUSTED_PROXY_COUNT` must now exist and be valid; missing/invalid config raises `ImproperlyConfigured` instead of silently defaulting proxy resolution off. Closes SA48.
  - **SA49 — Derive orgs' cross-module conformance-env module list instead of hand-listing it.** The hand-maintained `INSTALLED_APPS` list in orgs' conformance settings could silently diverge from the real module inventory, leaving isolation/purge/FK-conformance gates blind to unlisted modules. Added a CI gate that derives the expected module set from installed manifests and asserts parity. Closes SA49.
  - **SA50 — Fold orgs' `JsonApiMixin`/`JsonOrganizationAccessMixin` stack into one `OrgApiBaseView`.** The eight `OrgApi*` JSON views re-implemented SaaS-mode gating, auth checks, and org-role access control per view via a two-level mixin stack. Consolidated into a single base class; the old mixins are removed. Closes SA50.
  - **SA21.2 — Wire forms/blog throttles and IP logging to the shared canonical client-IP seam.** Added an importable `get_client_ip(request)` helper to orgs and repointed forms' submission IP logging, blog's API rate-limit throttle ident, and the forms submit throttle to it, closing a short-XFF-chain divergence with DRF's own IP resolution. Closes SA21.2.
  - **SA26 — Sanitize markdown-rendered URI schemes on public blog/listing detail pages.** Markdown `[text](javascript:...)` links rendered as unescaped `<a href="javascript:...">` under the `|safe` filter. Added an allowlist URI-scheme sanitizer (plus control-character/obfuscation normalization) run before rendering on both blog and listings detail pages; `http(s)`/`mailto`/relative links remain clickable. Closes SA26.
  - **SA40 — Reject non-string values on public form submit instead of 500ing.** Public form submissions now return validation errors for non-string field values and malformed `min_length`/`max_length` rule config instead of crashing. Closes SA40.
  - **SA41 — Distinguish "no subscription" from a subscription row missing its Stripe id during account-deletion billing cleanup.** Added a dedicated `BillingSubscriptionAnomalyError` so the benign "nothing to cancel" case and the anomalous "subscription exists but has no Stripe id" case are handled and logged separately instead of both failing silently. Closes SA41.
  - **SA42 — Make module post-hook settings reads fail hard instead of silently coercing.** Blog, listings, forms, and notifications post-hooks no longer default missing settings (page sizes, rate limits, feature flags) — a missing setting now raises at apply time instead of silently taking effect with a hidden default. Closes SA42.
  - **SA43 — Extract the async-restore dispatch lifecycle into a single service function.** The claim/spawn/rollback lifecycle for admin-triggered backup restore existed as two duplicated inline copies (recorded-artifact and uploaded-file paths); extracted into one shared `dispatch_background_restore()` service function so future fixes apply once. Closes SA43.
  - **SA51 — Rewrite the false `backups/services.py` header contract.** The header claimed the file was "intentionally under 400 LOC" and pointed new orchestration elsewhere; corrected to state the real division of responsibility between `services.py` (model-touching lifecycle) and `dr_engine/` (engine-pure logic). Closes SA51.
  - **SA52 — Fail hard when `manage.py` can't be resolved.** `_get_manage_py()` no longer falls back to a bare `"manage.py"` literal on resolution failure — a production deploy without a resolvable `manage.py` now fails dispatch immediately instead of reporting success while the child process dies. Closes SA52.
  - **SA54 — Guard the stale-restore threshold default against drift.** The DR orchestration layer's hardcoded 30-minute stale-restore threshold could drift from the module's canonical constant since core can't import module services; the constant is now injected explicitly by the caller and a regression test locks the default to match. Closes SA54.
  - **SA53 — Make the uploaded-restore-artifact copy crash-safe.** The upload-restore copy path could destroy the prior local artifact on a failed copy and leak its staging directory. Now uses a crash-safe fd-based copy with retry-on-short-write and consolidated cleanup, so a failed copy never destroys the existing artifact. Closes SA53 (including CR-SA53-REV-002).
    Follow-up (CR-SA26-001) hardened the SA26 sanitizer against tab/newline scheme obfuscation per the WHATWG URL spec.

  - **SA47 — Consolidate the last-owner deletion-blocking check into orgs as the canonical implementation, with concurrent-deletion protection.** Three divergent "never remove the last owner" implementations (model-level, account-deletion view, two org view duplicates) are now one canonical `OrganizationMembership.is_last_owner_with_members()` used everywhere, and account deletion now runs under `select_for_update` so concurrent deletions by co-owners can't both succeed and leave an org ownerless. Closes SA47.
  - **SA37 — Move admin backup create/prune off the synchronous request path.** Backup creation and pruning now dispatch via the same background-subprocess pattern as SA43's restore dispatch, so the admin action returns immediately instead of blocking on `pg_dump`/file deletion. Closes SA37.

Added an AST-based CI check requiring every `csrf_exempt` callsite to also call an approved verification helper. Closes SA46 (including CR-SA46-001/REV-002/REV-003, which hardened the gate's literal-truthiness evaluator against being fooled by constant-folded dead branches).
